# 奥德赛：归乡之路 (Odyssey: Nostos)

> 一款基于微信小程序平台的古希腊史诗题材剧情向文字冒险游戏 Demo。

---

## 📖 故事背景
特洛伊战争落幕，烈火化为余烬。你并非阿喀琉斯、阿伽门农，亦非受雅典娜眷顾的奥德修斯。你只是一名率领三十名同乡弟兄的希腊小邦船长。你的唯一目标，是在变幻莫测的爱琴海上穿过重重神明试炼与绝境，带领战船回到故土。

---

## ⚙️ 核心机制与物资系统

### 1. 一阶核心物资（直接受玩家决策影响）
* 🍖 **食物 (Food: 0~100)**：维持日常航行。断粮将引发饥荒，持续削减忠诚并造成减员。
* 🧠 **理智 (Sanity: 0~100)**：抵御塞壬幻音与深海诡异的精神力量。过低会引发船员恐慌。
* ✨ **神恩/幸运 (Luck: 0~100)**：波塞冬、阿波罗、雅典娜等神明的态度。达到一定阈值可解锁**神迹特殊分支**。

### 2. 二阶衍生受控物资（受一阶物资联动恶化影响）
* 👥 **存活船员 (Crew: 0~30 人)**：遭遇风暴、饥荒、发狂或海怪时减员。**归零触发【永恒迷航·幽灵船】结局**。
* 🛡️ **船员忠诚度 (Loyalty: 0~100%)**：断粮、船长陷入疯狂或做出极端决策将引发叛意。**归零触发【深海兵变】结局**。

---

## 🚀 如何在微信开发者工具中运行

1. 打开 **微信开发者工具**。
2. 点击 **「+」或「导入项目」**。
3. 选择此项目所在文件夹（即包含 `project.config.json` 的目录）。
4. AppID 选择 **「测试号」**（无需注册小程序账号即可直接本地体验）。
5. 点击 **「确定 / 导入」**，模拟器将立即加载游戏！

---

## 🕹️ Demo 包含的完整游戏功能
* 📜 **打字机叙事流**：逐字流畅输出，支持点击屏幕任意位置快速跳过。
* 🔀 **多分支与条件判定**：根据一阶/二阶物资动态开放或锁定隐藏选项。
* 💾 **多槽位存读档系统**：支持 3 个手动存储位与自动存档。
* 📜 **航海日志回顾 (Backlog)**：随时向上滚动查看往期对话与历史决策。
* ⚡ **自动航行模式 (Auto)**：开启后自动阅读并推进。
* 🏆 **多结局与航海档案结算**：包含【英雄凯旋】、【残破归客】、【深海兵变】、【永恒迷航】等史诗结局。
